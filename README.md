# Parkoveira API

Тестовый сервер для приложения Parkoveira на Aurora OS. Каталог содержит 15 700 парковок Москвы и 214 617 тарифных правил из наборов 623 и 1681. При первом запуске сервер распакует каталог и создаст локальную базу demo.sqlite. Аккаунты и брони сохраняются между запусками.

## Запуск на Linux

Нужны Python 3.11 или новее, SQLite 3.38 или новее, модуль venv и интернет для загрузки зависимостей. На Debian и Ubuntu пакет для виртуального окружения называется python3-venv. В терминале из каталога проекта выполните:

```sh
sh start.sh
```

Дождитесь сообщения Uvicorn о запуске. В другом терминале проверьте сервер:

```sh
curl http://127.0.0.1:8080/api/v1/health
hostname -I
```

Ожидаемый ответ — {"status":"ok"}. Документация методов доступна по адресу http://127.0.0.1:8080/docs. Остановить сервер можно сочетанием Ctrl+C.

## Подключение эмулятора

Откройте версию Parkoveira с экраном «Онлайн-бронирование». Введите http://IP-хоста:8080, используя доступный эмулятору адрес Linux-компьютера из вывода hostname -I. Нажмите «Проверить соединение». Внутри эмулятора 127.0.0.1 ведёт к гостевой ОС. Если сервер отвечает только с хоста, проверьте маршрут гостевой сети и доступ к TCP-порту 8080.

Демо-вход — demo@parkoveira.test, пароль DemoPark123. Выберите транспорт, первую парковку на схеме, длительность и «Рассчитать стоимость». Кнопка «Оплатить и забронировать» создаёт бронь и учебную квитанцию. Для платного примера выберите следующий понедельник. Проверить или отменить бронь можно в истории.

Сервер предназначен для локальной демонстрации с тестовыми данными. Настройки окружения PARKING_BIND и PARKING_PORT задают адрес и порт прослушивания (изначально 0.0.0.0 и 8080).

## Тест

После установки зависимостей выполните `.venv/bin/python -m unittest test_demo`. Тест использует отдельную временную базу.
